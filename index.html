让 Reachy Mini
用千问与你对话。

接入阿里云百炼的千问 Live 实时语音模型，让 Reachy Mini 听你说话、用语音回答；回答时，天线和头部也会配合做出动作。

🎙️ 千问 Live🤖 动作反馈💬 中文对话

如何开始

  1. 在 Discover apps 搜索 reachy-mini-qwen-live 并安装。
  2. 在百炼准备可调用千问 Live 实时语音模型的 API Key 和业务空间 ID。
  3. 启动应用，在设置页选择服务地域并填写凭据，点击“开始对话”。

本 Space 只是应用介绍和安装入口，不会索取或保存你的 API Key。

让习惯使用国内模型服务的 Reachy Mini 用户，也能用实时语音进行自然的中文对话，让动作随交流变化。
