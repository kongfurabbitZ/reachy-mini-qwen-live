REACHY MINI · 中文社区应用

让 Reachy Mini
用千问与你对话。

接入阿里云百炼的千问实时语音模型，用机器人的麦克风倾听、扬声器回答，同时保留有节制的天线与头部动作。

🎙️ 实时语音🤖 动作反馈🇨🇳 百炼北京地域

如何开始

  1. 在 Reachy Mini Control 的 Discover apps 中安装本应用。
  2. 在百炼获取北京地域的 API Key 和业务空间 ID。
  3. 启动应用，在本机设置页填写凭据，点击“开始对话”。

本 Space 只是应用介绍和安装入口，不会索取或保存你的 API Key。

查看安装文件与中文说明查看 GitHub 源码

为什么做这个应用？

让使用国内模型服务的 Reachy Mini 用户，也能尝试实时中文语音陪伴，而不必配置 OpenAI API Key。

目前的边界

已在 Mac M4 模拟器验证真实千问连接与文字转写。实体 Wireless 的声音听感、延迟和动作安全尚待验证。
